# Vimium Desktop (Rust) 🦀

Кроссплатформенный аналог браузерного расширения **Vimium** для всей операционной системы (Windows и Linux / Ubuntu).
Позволяет взаимодействовать с любыми приложениями (Word, Настройки, Проводник, Telegram, VS Code и др.) с помощью клавиатуры: находит все кликабельные элементы и выводит над ними плашки с буквами для быстрого клика.

---

## 🌟 Возможности новой версии

1. **Работа в системном трее (System Tray)**:
   - При обычном запуске (двойной клик по `.exe`) приложение тихо сворачивается в трей (рядом с часами).
   - Никаких черных консольных окон, мешающих работе.
2. **Глобальный хоткей (Global Hotkey)**:
   - В любом открытом приложении нажимаете горячую клавишу (по умолчанию **`Alt + F`**), и поверх кнопок целевого окна появляются желтые бейджи.
3. **Меню настроек в трее**:
   - Правый клик по иконке в трее открывает меню:
     - Выбор хоткея: `Alt + F`, `Alt + Пробел`, `Alt + ;` (Hunt-n-Peck), `Ctrl + Shift + F`.
     - **⚡ Пропускать браузеры (Chrome, Edge и др.)**: мгновенный отклик при открытом браузере.
     - **🚀 Автозапуск при старте Windows**: переключение автозапуска одним кликом с уведомлением.
     - Быстрый вызов подсказок и выход.
   - Все настройки автоматически сохраняются в `vimium_config.txt`.
4. **Автозапуск системы (Windows & Linux)**:
   - **Windows**: регистрация в реестре `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Запускается тихо в трей без прав администратора.
   - **Linux**: стандартная спецификация XDG Autostart (`~/.config/autostart/vimium-desktop.desktop`).
   - Управление доступно как через контекстное меню трея, так и через CLI: `vimium-desktop.exe autostart --enable`, `--disable`, `--status`.
5. **Обход панели задач и системного трея (Taskbar & Tray)**:
   - В поиск всегда включаются активное окно + панель задач Windows + системный трей (меню Пуск, закрепленные приложения, регулятор громкости/звука, дата и часы).
6. **⚡ Умный режим для браузеров (Smart Browser Navigation)**:
   - В браузерах (Chrome, Edge, Firefox, Yandex, Brave, Opera, Arc, Zen и др.) рабочая область страницы (HTML DOM) автоматически изолируется и исключается. Это исключает задержки от тысяч элементов веб-страницы и предотвращает конфликт с внутрибраузерными плагинами (Vimium / Vimium C).
   - При этом нативный интерфейс браузера сканируется мгновенно: подсвечиваются **вкладки** (`TabItem`), **кнопка создания вкладки** (`+`), **адресная строка / поиск** (`Edit`) и **панель навигации** («Назад», «Вперед», «Обновить», расширения, меню).
   - В меню трея доступен гибкий выбор режима: *«⚡ Вкладки и панель навигации (Рекомендуется)»*, *«🚫 Пропускать браузеры полностью»* или *«🌐 Сканировать всё (включая страницы)»*.
7. **Кэширующий обход UIA (FindAllBuildCache)**:
   - Загрузка всех свойств (BoundingRectangle, Name, ControlType, Patterns) за 1 IPC-вызов к системе вместо сотен последовательных обращений (отклик 30–50 мс).
8. **Полная независимость от раскладки (RU / EN)**:
   - Низкоуровневый системный хук перехватывает физические скан-коды клавиш. Работает идентично как при включенной английской, так и русской (`РУС`) раскладке.
9. **Многомониторные конфигурации**:
   - Автоматически находит элементы как на основном таскбаре (`Shell_TrayWnd`), так и на дополнительных мониторах (`Shell_SecondaryTrayWnd`).

## 📦 Установка

### Windows (Рекомендуется — через инсталлятор)
1. Скачайте **`vimium-desktop-windows-x86_64-setup.exe`** из раздела [**Releases**](https://github.com/jools333/Vimium-desktop/releases/latest).
2. Запустите инсталлятор и следуйте подсказкам мастера установки:
   - **Без прав администратора**: приложение устанавливается в стандартную пользовательскую папку (`%LOCALAPPDATA%\Programs\Vimium-desktop`), не вызывая раздражающих запросов UAC.
   - **Ярлыки**: автоматически создает ярлыки в меню «Пуск» и на Рабочем столе (с возможностью отключения).
   - **Автозапуск**: опция запуска вместе с Windows прямо на этапе установки.
   - **Чистое удаление**: регистрируется в «Параметры Windows → Приложения → Установленные приложения» со встроенным деинсталлятором.
   - **Тихая установка**: поддерживается ключ `/S` для автоматического развертывания.

#### Портативная версия (Portable):
Если установка не требуется, скачайте архив **`vimium-desktop-windows-x86_64.zip`** или файл **`vimium-desktop-windows-x86_64.exe`**, поместите в любую папку и запустите.

### Linux (Ubuntu / Debian / Linux Mint / Pop!_OS и др.)

#### Вариант 1: Установка через `.deb` пакет (Рекомендуется)
1. Скачайте пакет **`vimium-desktop_<версия>_amd64.deb`** из раздела [**Releases**](https://github.com/jools333/Vimium-desktop/releases/latest).
2. Установите пакет через терминал:
   ```bash
   sudo apt install ./vimium-desktop_*_amd64.deb
   # или через dpkg:
   # sudo dpkg -i vimium-desktop_*_amd64.deb
   ```
   Пакет автоматически установит:
   - Исполняемый файл в `/usr/bin/vimium-desktop`
   - Ярлык приложения в систему (`/usr/share/applications/vimium-desktop.desktop`)
   - Иконки в тему `hicolor` и `pixmaps`
3. Запуск доступен из меню приложений системы или командой `vimium-desktop`.
4. Для удаления пакета:
   ```bash
   sudo apt remove vimium-desktop
   ```

#### Вариант 2: Портативный бинарник (.tar.gz):
1. Скачайте архив **`vimium-desktop-linux-x86_64.tar.gz`** со страницы релизов.
2. Распакуйте и запустите:
   ```bash
   tar -xzf vimium-desktop-linux-x86_64.tar.gz
   chmod +x vimium-desktop-linux-x86_64
   ./vimium-desktop-linux-x86_64
   ```

## 🛠 Сборка из исходного кода

### Windows (PowerShell)
В репозитории подготовлены PowerShell-скрипты для автоматической компиляции и сборки Windows-инсталлятора:

```powershell
# Сборка релизной версии и упаковка готового Windows-инсталлятора (.exe setup)
.\scripts\build-windows.ps1

# Сборка только инсталлятора из уже скомпилированного бинарного файла:
.\scripts\build-installer.ps1

# Сборка отладочной (debug) версии без инсталлятора:
.\scripts\build-windows.ps1 -Debug -SkipInstaller
```
Готовый инсталлятор сохраняется по пути: `dist\vimium-desktop-windows-x86_64-setup.exe`.

### Linux (Bash)
Для сборки приложения и формирования `.deb` пакета на Linux / Ubuntu:

```bash
# 1. Установка необходимых библиотек:
sudo apt-get update && sudo apt-get install -y build-essential pkg-config libdbus-1-dev

# 2. Полная сборка релизной версии и сборка deb-пакета:
chmod +x scripts/*.sh
./scripts/build-linux.sh

# Или только упаковка deb-пакета из скомпилированного бинарника:
./scripts/build-deb.sh
```
Готовый пакет будет находиться в папке `dist/vimium-desktop_<версия>_amd64.deb`.

## 🚀 Запуск

### Основной режим (в системном трее):
Просто запустите файл:
[`vimium-desktop/vimium-desktop.exe`](file:///c:/Users/lotarev/Documents/antigravity/jolly-carson/vimium-desktop/vimium-desktop.exe)

Появится уведомление Windows: *"Vimium Desktop активен. Нажмите Alt+F в любом окне для навигации"*.
В правом нижнем углу появится иконка.

### Управление:
- Нажмите **`Alt + F`** в любом окне (Word, Explorer, Настройки системы, Telegram и т.д.).
- Поверх кнопок отобразятся буквы: `A`, `S`, `D`, `AA`...
- Нажмите буквы на клавиатуре (работает и в русской, и в английской раскладке!). Программа сразу кликнет по элементу.
- Нажатие **`Esc`** отменяет режим подсказок.
- Правый клик по иконке в трее открывает меню настроек.

## 🛠 Консольный режим (для отладки и скриптов)

- **Сканирование элементов активного окна**:
  ```powershell
  .\vimium-desktop\vimium-desktop.exe scan --delay-ms 2000
  ```

- **Управление автозапуском через консоль**:
  ```powershell
  # Включить автозапуск
  .\vimium-desktop\vimium-desktop.exe autostart --enable

  # Отключить автозапуск
  .\vimium-desktop\vimium-desktop.exe autostart --disable

  # Проверить статус
  .\vimium-desktop\vimium-desktop.exe autostart --status
  ```

- **Автообновление (проверка и установка новых версий с GitHub)**:
  ```powershell
  # Проверить наличие обновлений
  .\vimium-desktop\vimium-desktop.exe update --check

  # Скачать и установить последнее обновление
  .\vimium-desktop\vimium-desktop.exe update
  ```
  *(На Windows обновление также можно выполнить в 1 клик через контекстное меню в системном трее: «Проверить обновления...»)*
