# Vimium Desktop (Rust) 🦀

Кроссплатформенный аналог браузерного расширения **Vimium** для всей операционной системы (Windows и Linux / Ubuntu).
Позволяет взаимодействовать с любыми приложениями (Word, Настройки, Проводник, Telegram, VS Code и др.) с помощью клавиатуры: находит все кликабельные элементы и выводит над ними плашки с буквами для быстрого клика.

---

## 🌟 Возможности новой версии

1. **Работа в системном трее (System Tray)**:
   - При обычном запуске (двойной клик по `.exe`) приложение тихо сворачивается в трей (рядом с часами).
   - Никаких черных консольных окон, мешающих работе.
2. **Глобальный хоткей (Global Hotkey)**:
   - В любом открытом приложении нажимаете горячую клавишу (по умолчанию **`Alt + F`**), и поверх кнопок целевого окна появляются желтые бейджи.
3. **Меню настроек в трее**:
   - Правый клик по иконке в трее открывает меню:
     - Выбор хоткея: `Alt + F`, `Alt + Пробел`, `Alt + ;` (Hunt-n-Peck), `Ctrl + Shift + F`.
     - **⚡ Пропускать браузеры (Chrome, Edge и др.)**: мгновенный отклик при открытом браузере.
     - **🚀 Автозапуск при старте Windows**: переключение автозапуска одним кликом с уведомлением.
     - Быстрый вызов подсказок и выход.
   - Все настройки автоматически сохраняются в `vimium_config.txt`.
4. **Автозапуск системы (Windows & Linux)**:
   - **Windows**: регистрация в реестре `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Запускается тихо в трей без прав администратора.
   - **Linux**: стандартная спецификация XDG Autostart (`~/.config/autostart/vimium-desktop.desktop`).
   - Управление доступно как через контекстное меню трея, так и через CLI: `vimium-desktop.exe autostart --enable`, `--disable`, `--status`.
5. **Обход панели задач и системного трея (Taskbar & Tray)**:
   - В поиск всегда включаются активное окно + панель задач Windows + системный трей (меню Пуск, закрепленные приложения, регулятор громкости/звука, дата и часы).
6. **⚡ Оптимизация для браузеров (Skip Browsers)**:
   - В браузерах (Chrome, Edge, Firefox, Yandex, Brave, Opera, Arc и др.) уже есть собственное расширение Vimium, а обход многотысячного HTML DOM-дерева через OS Accessibility занимал несколько секунд.
   - При включенной опции (активна по умолчанию) Vimium Desktop мгновенно пропускает веб-дерево браузера (<20 мс) и подсвечивает кнопки панели задач и системного трея (звук, часы, переключение окон), не конфликтуя с родным плагином браузера.
7. **Кэширующий обход UIA (FindAllBuildCache)**:
   - Загрузка всех свойств (BoundingRectangle, Name, ControlType, Patterns) за 1 IPC-вызов к системе вместо сотен последовательных обращений (отклик 30–50 мс).
8. **Полная независимость от раскладки (RU / EN)**:
   - Низкоуровневый системный хук перехватывает физические скан-коды клавиш. Работает идентично как при включенной английской, так и русской (`РУС`) раскладке.
9. **Многомониторные конфигурации**:
   - Автоматически находит элементы как на основном таскбаре (`Shell_TrayWnd`), так и на дополнительных мониторах (`Shell_SecondaryTrayWnd`).

## 🚀 Запуск

### Основной режим (в системном трее):
Просто запустите файл:
[`vimium-desktop/vimium-desktop.exe`](file:///c:/Users/lotarev/Documents/antigravity/jolly-carson/vimium-desktop/vimium-desktop.exe)

Появится уведомление Windows: *"Vimium Desktop активен. Нажмите Alt+F в любом окне для навигации"*.
В правом нижнем углу появится иконка.

### Управление:
- Нажмите **`Alt + F`** в любом окне (Word, Explorer, Настройки системы, Telegram и т.д.).
- Поверх кнопок отобразятся буквы: `A`, `S`, `D`, `AA`...
- Нажмите буквы на клавиатуре (работает и в русской, и в английской раскладке!). Программа сразу кликнет по элементу.
- Нажатие **`Esc`** отменяет режим подсказок.
- Правый клик по иконке в трее открывает меню настроек.

## 🛠 Консольный режим (для отладки и скриптов)

- **Сканирование элементов активного окна**:
  ```powershell
  .\vimium-desktop\vimium-desktop.exe scan --delay-ms 2000
  ```

- **Управление автозапуском через консоль**:
  ```powershell
  # Включить автозапуск
  .\vimium-desktop\vimium-desktop.exe autostart --enable

  # Отключить автозапуск
  .\vimium-desktop\vimium-desktop.exe autostart --disable

  # Проверить статус
  .\vimium-desktop\vimium-desktop.exe autostart --status
  ```
